# PadChecker – Free Online Gamepad Tester

**PadChecker** is a free browser-based gamepad tester designed to help gamers check controller inputs, identify possible stick drift, and troubleshoot common gamepad problems.

🌐 **Official Website:** https://padchecker.com/

## Features

PadChecker provides several controller diagnostic tools in one browser-based interface.

- **Button Testing:** Monitor button presses and D-pad inputs in real time.
- **Analog Stick Testing:** Inspect joystick movement and input values.
- **Stick Drift Test:** Check for unwanted analog stick movement.
- **Circularity Test:** Evaluate analog stick movement across different directions.
- **Deadzone Preview:** Explore how deadzone adjustments affect stick input.
- **Trigger Testing:** Monitor analog trigger response.
- **Vibration Testing:** Test supported controller vibration functions.
- **Update Rate Monitoring:** Observe controller input updates reported through the browser.
- **Event Log:** Review controller input activity.
- **Test Reports:** Export diagnostic results for reference.

Some features depend on controller hardware, browser support, and operating system compatibility.

## Supported Controllers

PadChecker is designed to work with many controllers recognized by compatible browsers, including:

- PlayStation 5 DualSense
- PlayStation 4 DualShock 4
- Xbox Series X|S controllers
- Xbox One controllers
- Nintendo Switch Pro controllers
- Compatible USB and Bluetooth PC gamepads

Controller detection, button mapping, and advanced features may vary by device and browser.

## How to Test Your Controller

1. Visit **https://padchecker.com/**
2. Connect your controller using USB or Bluetooth.
3. Press a controller button to activate browser detection.
4. Check button inputs, analog sticks, triggers, and D-pad responses.
5. Run the available diagnostic tests.
6. Review the results and export a report if needed.

No account or additional testing software is required.

## Understanding Stick Drift

Stick drift occurs when an analog stick reports movement even when the user is not intentionally moving it.

PadChecker provides a stick drift diagnostic test to help identify unexpected input readings. Results should be interpreted alongside controller calibration, deadzone settings, and actual gameplay behavior.

## Privacy

PadChecker is designed to process controller input locally in the browser using the Web Gamepad API. Controller diagnostic testing does not require uploading controller input data to a server.
